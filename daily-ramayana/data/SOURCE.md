# Source Text

## Books 1–6 (Bāla, Ayodhyā, Araṇya, Kiṣkindhā, Sundara, Yuddha Kāṇḍa)
- **Translation:** *The Rámáyan of Válmíki, translated into English verse* by Ralph T. H. Griffith, M.A. (Benares / London, 1870–1874)
- **Source:** Project Gutenberg eBook #24869 — https://www.gutenberg.org/ebooks/24869 (plain text: https://www.gutenberg.org/cache/epub/24869/pg24869.txt)
- **License:** Public domain in the USA (translation published 1870–1874; translator d. 1906). Project Gutenberg license header/footer, front matter, appendices (French/Italian comparisons), additional notes, index and footnotes were removed, so this derived text is not a "Project Gutenberg" edition and carries no PG trademark.
- **Processing:** footnote reference markers like `(12)` removed; canto headings normalised to `## Canto N. Title`. Griffith himself abridged or omitted some cantos (esp. Book 1 XXXVII–XXXVIII, parts of Book 5, and Book 6 LXXVI–XCII); his bracketed `[I omit …]` notes are kept in place.
- Griffith's own volume gives only a short prose epitome of the Uttara Kāṇḍa, so Book 7 comes from another translation:

## Book 7 (Uttara Kāṇḍa)
- **Translation:** *The Ramayana, translated into English prose from the original Sanskrit of Valmiki — Uttarakandam* by Manmatha Nath Dutt (Calcutta, 1894)
- **Source:** Internet Archive item `TheRamayanaUttaraKandam` — https://archive.org/details/TheRamayanaUttaraKandam (OCR text: https://archive.org/download/TheRamayanaUttaraKandam/The_Ramayana_djvu.txt)
- **License:** Public domain (published 1894; translator d. 1912).
- **Processing:** page headers, "Digitized by Google" lines, most page-bottom footnotes and footnote markers removed; hyphenated line breaks rejoined; paragraphs re-flowed; section headings normalised to `## Section N` (OCR missed ~17 of the 124 section headings, so those sections run on inside the previous one). Common OCR name errors fixed (Havana→Ravana, Rlma→Rama, R&ma→Rama …), but **other OCR errors remain** — the lecture should silently correct them from context.

# 讲稿风格指南 / Style Guide

目标：**忠于原文、讲清故事、讲透文化、不臆造**。听众是中文母语、对印度神话不熟、但喜欢《西游记》和历史的成年人。

---

## 总原则

1. **忠于原文**：只讲 `progress.py next` 返回的 `text`。可以补充背景，但不得把本段没有的情节写进"译述"。
2. **故事优先**：每期先让听众明白"谁、在哪、发生了什么、为什么"，再讲文化。
3. **译名统一**：一律用 `references/structure.md` 的中文译名表；首次出现写 "罗什曼那（Lakṣmaṇa）"。表中没有的人名/地名，音译后在讲稿末尾不必列出，但同一期前后一致。
4. **译者略写如实交代**：遇到 Griffith 的 `[I omit …]` 方括号说明，写"英译者格里菲斯此处略去 X 章，大意是……"。
5. **第 7 篇是 OCR 文本**：遇到明显的识别错误（如 Havana=Ravana、字母错乱），按上下文默默纠正，不要把错字当原文引用。
6. **神话照实讲、点到为止**：恩典、诅咒、神兵、化身如实译述；背景讲解里可以说明其宗教含义或象征，但不要说教。
7. **《西游记》关联要克制**：只在情节真正可比时提（哈奴曼、跳海、变身、钻肚、移山等），并说明"原型说"是学术争论而非定论。
8. **不掉书袋**：dharma、tapas、avatāra 等术语给一句白话解释。

## 结构

### 📜 原文节录（英文）
- 引用 `text` 中最有代表性的 6–16 行诗（或 2–4 句散文），用 `>` 引用块；诗行保留分行（行末加两个空格或每行单独一个 `>` 行）。
- 不要整段照搬；其余在译述里覆盖。

### 🗣️ 中文译述
- 按情节顺序，用流畅现代汉语译述本段**全部**内容（不是只译节录部分），可分小标题【……】。
- 诗体原文译成散文即可；关键台词可以译得有韵味些。
- 数字、名号、恩典条件要准确。

### 📚 背景讲解（3–5 要点）
按本段取舍：
- 本段在全书主线中的位置（第几篇、刚发生了什么）
- 印度宗教与文化：神祇、仪式（马祭、灌顶）、种姓、四行期、法、恩典与诅咒
- 地理：阿逾陀、恒河、频阇耶山、楞伽等今地（如能确定）
- 文学：诗律（输洛迦 śloka）、插话结构、后世改编（《罗摩功行录》、泰国《拉玛坚》、印尼皮影）
- 与中国的联系：汉译佛经中的罗摩故事、哈奴曼与孙悟空（仅在相关时）

### 🔮 下期预告
一两句，勾起好奇，不剧透太多。

## 配图 prompt 风格
- **印度细密画（Indian miniature painting）**风格：拉杰普特 / 帕哈里（Pahari, Kangra）/ 莫卧儿宫廷画风，平涂矿物颜料、金色勾边、装饰性花边框、侧脸人物、程式化树木与宫殿。
- 选本期最有画面感的一幕，**写清人物、动作、场景**；罗摩常画为蓝肤持弓王子，哈奴曼为猴形神将。
- 16:9 横幅；画面不要文字，或仅有极少装饰性文字。
- 不画真实存在的人物肖像；神祇按传统图像学描绘即可。

## 语音稿风格
- 中文 300–800 字，娓娓道来、像讲故事；开头"每日罗摩衍那，第 N 期。"
- 内容：本期情节主线 + 一个文化要点 + 下期预告。
- 只写可朗读的纯文本：不要 markdown 符号、英文长段、路径、数字编号列表；梵文名只读中文译名。

## 长度
- 中文讲稿正文目标 **1200–2200 字**（译述 + 讲解都要展开）。
- 不要为了赶配图/语音把正文压成提纲。
